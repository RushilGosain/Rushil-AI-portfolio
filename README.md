# 🤖 AI Portfolio – Interactive Developer Portfolio

A modern AI-powered portfolio website showcasing my skills, projects, certifications, trainings, and professional journey. The portfolio features an intelligent chatbot powered by the Groq API that can answer questions about my background, technical expertise, projects, and experiences in real time.

---

## 🚀 Live Demo

🌎 **Portfolio Website:** [https://rushil-ai-portfolio.netlify.app/]


---

## ✨ Features

* 🤖 **AI Portfolio Assistant** – Interactive chatbot that answers questions about my profile, projects, skills, and experience.
* 🎨 **Modern User Interface** – Clean and professional design with smooth animations and responsive layouts.
* 👨‍💻 **About Section** – Highlights my background, interests, and career objectives.
* 🛠️ **Skills Showcase** – Displays technical skills, programming languages, frameworks, and tools.
* 🎓 **Trainings & Experiences** – Dedicated section for internships, industrial training, and professional experiences.
* 🚀 **Projects Portfolio** – Showcases featured development and AI projects with detailed descriptions.
* 📜 **Certifications Section** – Displays industry certifications and achievements.
* 📞 **Contact Section** – Easy ways to connect through email, LinkedIn, and GitHub.
* 📱 **Fully Responsive** – Optimized for desktop, tablet, and mobile devices.
* ⚡ **Fast Backend Processing** – Python-powered backend integrated with Groq API for low-latency responses.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/ai-portfolio.git
cd ai-portfolio
```

### 2. Install Frontend Dependencies

```bash
npm install
```

### 3. Install Backend Dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend directory:

```env
GROQ_API_KEY=your_groq_api_key
```

---

## ▶️ Run the Project

### Start Frontend

```bash
npm run dev
```

### Start Backend

```bash
python app.py
```

The frontend will run on:

```text
http://localhost:3000
```

The backend API will run on:

```text
http://localhost:5000
```
